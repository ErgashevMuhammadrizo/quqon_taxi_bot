FEATURES

Asosiy Xususiyatlar

Har bir funksiya production-grade va kengaytiriladigan

Perceptual Hash Matching

Rasm va videolarni pHash, dHash, aHash algoritmlari bilan solishtiradi. Kichik ozgarishlarga chidamli - screenshot, crop, compress qilingan ham aniqlaydi.

OCR Text Analysis

Tesseract + EasyOCR bilan rasm ichidagi matnni oqiydi. Screenshot olingan postlarni matn orqali aniqlaydi. Multilingual qollab-quvvatlaydi.

Invisible Watermark

Rasmlarga kozga korinmas watermark (DCT-based) qoshadi. Ogirlangan kontentni watermark orqali manbaiga qaytarib topadi.

detection_engine.py CORE 
01 class ContentDetector:
02     def __init__(self):
03         self.hash_store = PerceptualHashStore()
04         self.ocr_engine = OCRAnalyzer()
05         self.watermarker = DCTWatermarker()
06 
07     async def analyze(self, message: Message):
08         scores = {}
09 
10         # 1. Perceptual Hash Check
11         scores['phash'] = await self.hash_store.compare(
12             message.photo[-1].file_id
13         )
14 
15         # 2. OCR Text Extraction
16         scores['ocr'] = await self.ocr_engine.extract(
17             message.photo[-1].file_id
18         )
19 
20         # 3. Watermark Verification
21         scores['watermark'] = await self.watermarker.verify(
22             message.photo[-1].file_id
23         )
24 
25         return DetectionResult(scores)

Auto-Ban System

Risk score 80%+ bolsa avtomatik ban. Admin tasdiqlash rejimi ham mavjud. Ban sababi, vaqti, evidence bilan saqlanadi.

Forward Detection

Forward qilingan xabarlarni aniqlaydi. Forward qilgan foydalanuvchini ID, vaqti, post ID bilan loglaydi.

Rate Limiting

Bir foydalanuvchi 1 daqiqada 5 tadan kop forward qilsa, avtomatik cheklanadi. Scraper botlarni ushlaydi.

06     async def execute_ban(self, user_id: int, chat_id: int,

middleware.py - Throttling PRO 
01 class ThrottlingMiddleware(BaseMiddleware):
02     def __init__(self, rate_limit=1, period=1):
03         self.rate_limit = rate_limit
04         self.period = period
05         self.throttler = Throttler(rate_limit, period)
06 
07     async def __call__(self, handler, event, data):
08         user = data.get('event_from_user')
09         if not user:
10             return await handler(event, data)
11 
12         throttled = await self.throttler.check(user.id)
13         if throttled:
14             await event.answer(
15                 'Juda kop so'rov. Iltimos kuting...'
16             )
17             return
18 
19         return await handler(event, data)
